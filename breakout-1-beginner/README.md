# Breakout 1 (beginner): Choosing Your First NaNDA Dataset

Beginner session, 45 minutes. Facilitator: Lindsay Gypin (she|her), Data Librarian and Senior Project Manager, University of Michigan, Institute for Social Research.

Pick this session if you are new to neighborhood data, or want help finding the right dataset. You'll leave with a NaNDA dataset matched to your geography and years.
