Slide 17: What is NaNDA?

Image: NaNDA, National Neighborhood Data Archive, logo

The National Neighborhood Data Archive (NaNDA) is an open data repository. It provides FAIR datasets about physical and social environment that researchers can easily combine with their own data.

Slide 23: Which geography do I use?

IF YOUR DATA HAVE…

JOIN TO NANDA USING…

A census tract, FIPS code, or GEOID (11 digits)

→

The FIPS code directly. Check whether it uses 2010 or 2020 geographic boundaries: tract_fips10 and tract_fips20 are not interchangeable

A ZIP code

→

A ZIP-code-to-ZCTA crosswalk. Some ZIP codes have no ZCTA

Full street addresses (not PO boxes)

→

Geocode first, in ArcGIS or an online geocoder, then join on the resulting FIPS code
